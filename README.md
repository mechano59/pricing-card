Subscription Plans Webpage
Overview
A responsive webpage showcasing Basic, Standard, and Premium subscription plans using HTML, CSS, and JavaScript. Built with Bootstrap, Font Awesome, and Google Fonts.
Features

Responsive layout with Bootstrap grid.
Interactive cards with hover effects and selection state.
Custom CSS with gradients and animations.
Plan selection via JavaScript.

File Structure

index.html: Contains HTML, inline CSS, and JavaScript.

Installation

Download or clone the project.
Open index.html in a browser (requires internet for CDNs).

Usage

View plans, hover for effects, click to select.
Responsive on all devices.

Customization

Edit plan details in HTML.
Modify CSS variables in :root.
Adjust JavaScript for new interactions.

Notes

Uses CDN-hosted Bootstrap 5.3.0-alpha1, Font Awesome 6.0.0, and Google Fonts.
Includes Cloudflare challenge script.
